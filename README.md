# Paradise Nursery 🌿 (e-plantShopping)

## 📌 Project Overview
Paradise Nursery is a front-end React shopping application where users can browse a variety of houseplants and add them to a shopping cart. The application demonstrates a complete e-commerce flow including product listing, cart management, and dynamic updates using React and Redux.

This project is part of the **e-plantShopping** learning assignment and is deployed using GitHub Pages.

---

## ⚙️ Tech Stack
- React.js
- JavaScript (ES6+)
- Redux Toolkit (Cart State Management)
- HTML5
- CSS3
- Git & GitHub Pages (Deployment)

---

## 🧠 State Management
Cart functionality is handled using Redux:
- Add items to cart
- Increase / decrease quantity
- Remove items
- Calculate total quantity and price dynamically

---

The application is deployed using **GitHub Pages**.
